# 📊 إدارة البيانات — النظام المحاسبي

تطبيق محاسبي عربي متكامل لإدارة الحسابات الشخصية والتجارية والعملاء والموردين والديون والمعاملات المالية والسندات والتقارير. يعمل **دون إنترنت** بشكل كامل، بواجهة عربية RTL أنيقة وخفيفة وسريعة.

---

## ✨ المزايا

### لوحة التحكم
- ملخص مالي: إجمالي المستحق لنا، المستحق علينا، صافي الرصيد، الإيرادات/المصروفات.
- ملخص الأرصدة حسب العملة (دون خلط العملات).
- آخر العمليات، الحسابات الأكثر نشاطاً، تنبيهات الديون والحدود الائتمانية.
- رسوم بيانية يومية وشهرية + اختصارات سريعة.

### الحسابات (عملاء / موردون / حسابات عامة)
- رصيد افتتاحي بطبيعته (له/عليه)، عملة، هاتف، واتساب، تصنيف، حد ائتماني، حالة، علامات، صورة.
- بحث سريع ومتقدم، فلترة بالتصنيف/العملة/الحالة، ترتيب متعدد.
- أرشفة بدل الحذف + سلة محذوفات للاستعادة.
- صفحة كشف حساب: رصيد، إجمالي له/عليه، سجل زمني، تصفية بفترة ونوع، تصدير PDF وExcel ومشاركة واتساب.

### العمليات المالية
- قبض، صرف، مبلغ له/عليه، إيراد، مصروف، تحويل بين الحسابات، تسوية.
- تفاصيل بيع اختيارية من شاشة العملية: الصنف، الكمية، الوحدة، سعر الوحدة، وإجمالي كل بند.
- تحديث **فوري وتلقائي** للرصيد مع منع الأخطاء الحسابية وكشف العمليات المكررة.
- مرفقات، مرجع، وقت، حالة، سجل تدقيق، تكرار عملية بنقرة، آلة حاسبة سريعة.
- بيع آجل/جزئي: تجهيز سند مصوّر بالنص والبنود وإرفاقهما للمشاركة عبر واتساب عند دعم الجهاز، مع إظهار فشل الإرفاق بدل إرسال النص منفردًا.

### المخزون والأصناف
- إضافة وتعديل وحذف الأصناف، الأسعار، الوحدة، الكمية الحالية، وحد التنبيه.
- اختيار الصنف داخل تفاصيل البيع فقط؛ لا توجد في هذه الشاشة وظائف شراء أو بيع أو مرتجع أو تسوية أو سجل حركات.

### العملات
- الريال اليمني، الدولار، الريال السعودي + إضافة عملات أخرى.
- أرصدة مستقلة، أسعار صرف، أداة تحويل، عملة افتراضية.

### السندات الاحترافية
- سند قبض/صرف/قيد مدين/قيد دائن/تحويل بتصميم A4 رسمي.
- ترقيم تلقائي، معاينة، طباعة PDF، مشاركة واتساب.
- اعتماد/إلغاء مع سجل، وتخصيص الشعار والبيانات والعبارة السفلية من الإعدادات.

### التقارير
- ملخص المبالغ، تفصيل العمليات، التصنيفات، يومي/أسبوعي/شهري/سنوي، حسب العميل/المورد، حسب العملة، الإيرادات والمصروفات، الأرباح والخسائر، أكثر الحسابات مديونية/نشاطاً، العمليات المستحقة.
- معاينة + تصدير PDF وExcel + مشاركة.

### التواصل والتنبيهات
- واتساب مباشر، إرسال كشف حساب وسند، قوالب رسائل.
- تنبيهات استحقاق، تجاوز الحد الائتماني، عمليات متأخرة.
- دردشة داخلية بين المستخدمين (نص، صور، سندات، كشف حساب، إنشاء عملية من رسالة).

### النسخ الاحتياطي والمزامنة
- نسخ احتياطي محلي واستعادة، تصدير/استيراد قاعدة البيانات JSON، نسخ تلقائي، سجل النسخ، تحذير قبل استبدال البيانات.

### المستخدمون والصلاحيات والأمان
- أدوار: مدير، محاسب، موظف إدخال، عرض فقط + صلاحيات تفصيلية.
- قفل PIN، إخفاء الأرصدة، قفل تلقائي، تأكيد قبل الحذف، سجل نشاط.

### الإعدادات
- المظهر (فاتح/ليلي/تلقائي)، حجم الخط، مسميات «له/عليه»، النشاط التجاري (الاسم والشعار والعنوان)، ترقيم السندات، التصنيفات، خدمة العملاء عبر واتساب.
- رفع/استبدال/حذف ومعاينة شعار المؤسسة؛ يُحفظ محليًا ويُعاد استخدامه في السندات وملفات PDF والصور، مع ترويسة نصية بديلة عند غيابه أو فشل تحميله.

## 🛠️ التقنية

- **Vanilla JavaScript (ES Modules)** — بدون أي مكتبات خارجية → حجم خفيف وسرعة عالية.
- **IndexedDB** — قاعدة بيانات محلية تعمل دون إنترنت بالكامل.
- **PWA + Service Worker** — تثبيت التطبيق والعمل دون اتصال.
- **محرك محاسبة مخصص** يضمن دقة الأرصدة (الرصيد = الافتتاحي + مجموع آثار العمليات).
- **تصدير PDF** عبر الطباعة، و**Excel/CSV** عبر HTML/CVS — دون مكتبات ضخمة.

## 🚀 التشغيل

```bash
# تشغيل سريع بدون أي تبعيات
npx serve .
# أو عبر node
node server.js
```

ثم افتح المتصفح على العنوان المعروض.
